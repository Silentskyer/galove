# 桌機與手機版 QA 清單

目前執行環境未安裝 Node.js / npm，因此尚未完成實機啟動測試；先建立上線前應逐項確認的檢查表。

## 桌機版

- 首頁 hero 區塊在 1280px 以上不應出現文字與吉祥物重疊
- 三個主題卡、三個模組卡在桌機版應維持等高感與合理留白
- 主題頁表單與結果區在 1024px 以上應採雙欄配置
- Header 與 footer 導覽在常見寬度下不應換行過度

## 手機版

- Header 導覽應能自然換行，不擠壓品牌名稱
- Hero 吉祥物在 390px 左右寬度下不應超出卡片
- 表單欄位、chip 與按鈕應能單手點擊，不發生水平捲動
- 結果卡片與法律頁文字應維持舒適行高

## 互動與錯誤

- 送出中應出現 loading 狀態
- API 失敗時應顯示明確錯誤訊息與重試入口
- 缺少 `GEMINI_API_KEY` 時應顯示可理解的設定提示
- 高風險 / 敏感問題應被安全規則攔下，不直接進行命運解析
